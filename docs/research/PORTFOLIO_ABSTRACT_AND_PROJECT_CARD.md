# Portfolio Abstract + Project Card

## Project card

**SSM / Semantic Software Markup — Specification-Conditioned Evolution Assurance for AI-Assisted Software Generation**
Independent research and systems-engineering project · working technical report · not peer reviewed

Designed and implemented a general-purpose application-generation compiler that transforms natural-language requirements through typed semantic intermediate representations before deterministic target generation. The V2.6 dev.2 architecture introduces a CanonicalSemanticContext shared by offline and online synthesis so that LLM-generated SML cannot redefine product semantics without passing an explicit SemanticConformanceVerifier. The research layer adds content-addressed run records, stage fingerprints, replay/determinism evidence, behavioural contracts, paired evolution assays, change-intent envelopes, capability slices and first-changed-stage attribution.

For Study 1, I designed SSM-Bench v2: 30 evaluator-separated end-to-end case packs spanning structured and unstructured requirements, CRUD, workflows, RBAC, tenancy, audit, integrations, NFRs, ambiguity, contradiction and unsupported requests. A 30×1 qualification run completed without evaluator failure and exposed measurable weaknesses in the current deterministic semantic front-end. A formal offline experiment then used 300 baseline and 300 no-change paired observations plus controlled regression and intended-evolution interventions. The unchanged control returned `NO_MATERIAL_CHANGE`; three known degradations returned `REGRESSION` with correct first-stage attribution; and an approved non-semantic change returned `INTENDED_EVOLUTION` while protected semantic metrics remained unchanged.

**Research direction:** source-level mutation testing, model/provider drift under fixed canonical semantics, negation-aware requirements interpretation, independently adjudicated semantic oracles, larger held-out benchmarks and sequential production evolution monitoring.

## Abstract

AI-assisted software generation is frequently evaluated at the level of final source code, obscuring the semantic transformations that connect natural-language intent to executable systems. This project presents SSM, an experimental application-generation compiler that separates deterministic semantic interpretation from probabilistic synthesis. Raw requirements are transformed through RequirementsIR, application-foundation planning, architecture resolution, capability composition and negotiation into a CanonicalSemanticContext. Offline synthesis renders SML deterministically, while online synthesis is constrained by the same context; candidate SML must pass semantic conformance before entering the deterministic compiler. To study generator evolution, the platform records content-addressed stage identities and paired evidence. SSM-Bench v2, a frozen 30-case benchmark with evaluator-only semantic oracles and independent runtime contracts, was used in a controlled offline study. The no-change arm produced 300/300 identical paired stage and metric observations and was classified as `NO_MATERIAL_CHANGE`. Controlled requirements-, SML- and generated-tree degradations were classified as `REGRESSION` and attributed to their injected first changed stages. A declared non-semantic generated-tree change was classified as `INTENDED_EVOLUTION` under an approved change envelope. Qualification also exposed current front-end limitations in domain inference, negation handling, custom rule preservation and no-auth representation. The results position SSM as a research platform for reproducible, evidence-backed evolution assurance in AI-assisted software-generation systems rather than solely as a code-generation tool.
